## 📌 Problem Statement

A system to track street light faults reported by citizens, manage their repair status, and help municipal authorities identify pending issues and frequently failing areas.

---

## 🎯 Objective

- Record street light faults with location details  
- Track status (Pending / Fixed)  
- Enable search and filtering  
- Display number of records dynamically  
- Improve visibility of unresolved complaints  

---

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript  
- Data Source: JSON file  
- Tools: VS Code, GitHub

## 📊 Features

### ✅ Data Loading
- Loads fault data from JSON file  
- Displays all records in table  

### 🔍 Search
- Search by street name  
- Case-insensitive  

### 🎯 Filter
- Filter by status:
  - All
  - Pending
  - Fixed  

### 📈 Record Count
- Shows number of displayed records  

### 💻 Simple UI
- Clean and easy to use  
- Table format display  

---

## 🖥️ How It Works

- Data is fetched from `data.json`
- Displayed in a table
- Search filters street names
- Dropdown filters status
- Count updates dynamically
